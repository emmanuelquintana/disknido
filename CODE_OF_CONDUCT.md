# Code of Conduct

We want DiskNido to be a welcoming project for everyone, regardless of
experience, background, identity or language (Spanish and English are both
first-class here).

**Expected:** be respectful and patient, assume good intent, give and accept
constructive feedback, focus on what is best for users and their data.

**Not acceptable:** harassment, insults or personal attacks, discriminatory
language or imagery, publishing others' private information, sustained
disruption.

**Scope:** project spaces (issues, pull requests, discussions) and public
spaces where someone represents the project.

**Enforcement:** report incidents privately to the maintainers through a
GitHub security advisory or a direct message to the repository owner.
Maintainers may edit or remove contributions and temporarily or permanently
ban participants who violate this code. Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
